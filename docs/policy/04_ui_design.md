# 4. UI デザイン

## 配色方針

UI はダークモードを基本とし、背景は黒に近い濃色、文字・個体・領域の枠は灰色がかった白とする。背景、文字、枠線、状態表示など、特定の意味を持たない要素には色相を持つ色を使わない。

現在のシミュレーション表示も濃色の地に灰白色の個体と領域枠を描く単純な配色とする。白を少し暗くした色を使い、長時間見続けても刺激が強くなりすぎないようにする。接続状態は色の変化で表現せず、状態テキストで表現する。

将来、個体の遺伝子特徴やその他の明確な意味を持つ属性を可視化する場合に限り、色を情報の符号化に使う。その場合も、装飾目的の色と混同しないようにする。

## 実装ルール

- UI の背景は黒に近い濃色、主要な文字・個体・領域の枠は灰色がかった白とする。
- 補助的な文字には灰白色の濃淡だけを使う。
- シミュレーションのキャンバスは濃色、個体と領域の枠は灰白色とする。
- 状態や操作の差異は、まず文字、形状、配置で表現する。
- simulationの実時間状態は `normal` を青、`lagging` を赤で補助的に表現し、色だけに依存しない。
- simulationの可視化windowとsimulation空間のwallは分離し、camera zoomではwallだけが拡大縮小される。
- 色を使う場合は、遺伝子特徴などの意味を持つデータとの対応を設計書に明記する。
